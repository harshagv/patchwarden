If your host uses cPanel

  1. Log in to cPanel and open Security → Manage API Tokens.
  2. Press Create. Name it patchwarden, and set an expiry date (for example, 90 days).
  3. Copy the token. cPanel shows it only once.
  4. Paste it below as a cpanel_token.

A cPanel token works for the whole account, so create one just for Patchwarden and delete it when you no longer need it.

If your host uses Plesk

  1. Ask your host for a Plesk API key for your subscription, or, if you manage the server, create one with plesk bin secret_key --create.
  2. Paste it below as a plesk_token.

WordPress without hosting-panel access

Use the Patchwarden plugin instead. It can update plugins and themes after you approve, but it can't change PHP.
